## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `turnover_records` | 离职记录 | 是 | 脱敏后的岗位、校区、日期和类型 |
| `staffing_data` | 编制与在岗数据 | 是 | 按周期和岗位 |
| `workload_data` | 工作量数据 | 否 | 负荷和排班 |
| `performance_distribution` | 绩效分布 | 否 | 只使用汇总，不用于个体惩罚 |
| `employee_survey` | 员工调查摘要 | 否 | 匿名和自愿 |
| `key_events` | 关键管理事件 | 否 | 制度调整、搬迁或薪酬变化 |
| `campus_job_labels` | 校区与岗位标签 | 是 | 用于分层分析 |
| `review_period` | 复盘周期 | 是 | 季度或半年 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

不能把相关性写成因果；员工数据敏感；调查需自愿和匿名保障；不得用于个体惩罚。
