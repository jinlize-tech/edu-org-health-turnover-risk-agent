# JLZ-EDU-AG-028 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-042`
- 正式产品：`JLZ-EDU-AG-028` / 组织健康与离职风险诊断
- 类型：Agent

- 业务中心：13 组织与人才效能中心

- 产品版本：`1.0.0`

## 2. 用户、痛点与目标

- 用户：校长、HR、区域负责人、组织发展人员
- 痛点：离职往往被看作个人选择，忽视排班、管理关系、角色冲突、薪酬公平和沟通问题。
- 目标：综合离职、负荷、绩效、管理反馈和员工声音，形成组织健康假设、风险矩阵和改进实验。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `turnover_records` | 离职记录 | array | 是 |
| `staffing_data` | 编制与在岗数据 | array | 是 |
| `workload_data` | 工作量数据 | array | 否 |
| `performance_distribution` | 绩效分布 | array | 否 |
| `employee_survey` | 员工调查摘要 | array | 否 |
| `key_events` | 关键管理事件 | array | 否 |
| `campus_job_labels` | 校区与岗位标签 | array | 是 |
| `review_period` | 复盘周期 | string | 是 |

## 4. 工作流

1. 确定范围
2. 数据脱敏
3. 趋势与分层
4. 生成根因假设
5. 设计访谈/验证
6. 制定改进项目
7. 复测

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点脱敏离职数据、编制/工时、绩效分布、培训、员工调查、关键事件、校区/岗位标签，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕综合离职、负荷、绩效、管理反馈和员工声音，形成组织健康假设、风险矩阵和改进实验。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确定范围 → 数据脱敏 → 趋势与分层 → 生成根因假设 → 设计访谈/验证 → 制定改进项目 → 复测设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `组织健康诊断`
- `离职风险热区`
- `改进计划`

## 7. 差异化与排重

- 与现有产品：教师发展关注个体能力；劳动合规检查看规则风险；本产品诊断组织层面的健康和流失驱动。
- 排重检查：部分重叠；共享教师/人力数据，但输出组织诊断和多因素验证。
- 独立理由：只安装本 Agent 即可独立运行组织健康专项。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
